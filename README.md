# statistical-analysis-guide

Plan, explore, and choose statistical methods with an interactive research analysis guide.

## Languages

The application is designed for:
- 🇮🇷 فارسی (Persian)
- 🇬🇧 English
- 🇫🇷 Français

## Features

- Interactive statistical-analysis planning
- Discipline-specific pathways
- CSV upload and browser-side diagnostics
- Descriptive statistics and assumption checks
- Statistical method recommendations
- No CSV data is uploaded to a server by the application

## Live demo

https://hoomanquant.github.io/statistical-analysis-guide/

## Disclaimer

This tool is a research-planning assistant, not a substitute for a qualified statistician, supervisor, or domain expert. Final analysis should be based on the actual study design, data, assumptions, and reporting requirements.
